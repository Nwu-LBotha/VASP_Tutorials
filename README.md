# VASP Hands-on: Computational Materials Modelling

## About this repository

This repository contains a collection of practical, hands-on tutorials for computational materials modelling using the **Vienna Ab initio Simulation Package (VASP)** and related computational tools.

The tutorials are intended for students, postgraduate researchers and beginners who want to develop practical skills in density functional theory (DFT), atomistic simulations and computational materials science.

The aim is to provide step-by-step examples covering the preparation of crystal structures, setting up VASP calculations, analysing simulation results and using additional computational tools to investigate the structural, electronic, magnetic and dynamical properties of materials.

Each tutorial is organised into a separate folder and includes relevant input files, calculation procedures, example results and explanations of the computational methods used.

## Tutorial topics

The repository will progressively cover different aspects of computational materials modelling, including:

| Topic                               | Description                                                                                                                                                          |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Structure preparation**           | Obtaining crystal structures, manipulating CIF files, generating supercells and preparing VASP input structures using pymatgen and other tools.                      |
| **Bulk materials**                  | Structural optimisation and investigation of bulk material properties.                                                                                               |
| **Magnetic properties**             | Non-magnetic, ferromagnetic and antiferromagnetic calculations, including the determination of local magnetic moments.                                               |
| **Electronic properties**           | Density of states (DOS), projected density of states (PDOS) and electronic band structures.                                                                          |
| **Molecular dynamics (MD)**         | Setting up and analysing molecular dynamics simulations, including different statistical ensembles and thermostats.                                                  |
| **Atomistic simulations using ASE** | Building structures, preparing calculations, manipulating atomic configurations and analysing simulation trajectories using the Atomic Simulation Environment (ASE). |
| **Computational analysis**          | Extracting, processing and visualising VASP results using Python and other analysis tools.                                                                           |

Additional topics and examples will be added as the repository develops.

## Software and tools

The tutorials make use of several computational materials modelling tools and resources:

* [VASP](https://www.vasp.at/) – Electronic-structure calculations and atomistic simulations.
* [Materials Project](https://materialsproject.org/) – Accessing computational materials data and crystal structures.
* [pymatgen](https://pymatgen.org/) – Crystal structure manipulation and materials analysis.
* [ASE](https://ase-lib.org/) – Atomic structure manipulation, simulation workflows and trajectory analysis.
* [VASPKIT](https://vaspkit.com/) – Preparation and analysis of VASP calculations.
* [Python](https://www.python.org/) – Data processing, automation and visualisation.

Additional software requirements will be specified in the individual tutorials.

## Getting started

Each tutorial is provided in its own directory and can be followed independently, provided that the required software and input files are available.

It is recommended to:

1. Read the background information provided with each tutorial.
2. Download or prepare the required input structures.
3. Follow the calculation instructions and prepare the VASP input files.
4. Run the calculations using your available computational resources.
5. Analyse the output files and compare your results with the examples provided.

The tutorials are intended primarily for educational and research training purposes. The supplied computational parameters are starting points and should be tested for convergence before being applied to independent research projects.
