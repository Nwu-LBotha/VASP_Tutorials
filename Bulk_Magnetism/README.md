# VASP Hands-on: Bulk Magnetism

## About this tutorial

This repository contains a collection of hands-on tutorials introducing the calculation of magnetic properties in bulk materials using the Vienna Ab initio Simulation Package (VASP).

The tutorials are designed for beginners who want to learn how to set up and perform spin-polarised density functional theory (DFT) calculations and investigate different magnetic configurations.

The practical examples focus on comparing non-magnetic, ferromagnetic and antiferromagnetic configurations, calculating magnetic moments and evaluating the relative energetic stability of different magnetic states.

## Tutorial contents

The repository is organised into background material and individual practical examples.

| Section                | Description                                                                                 |
| -----------------------| ------------------------------------------------------------------------------------------- |
| Background             | Introduction to magnetism, magnetic configurations and the relevant VASP input parameters.  |
| 01 – Nickel (Ni)       | Non-magnetic and ferromagnetic calculations of fcc nickel.                                  |
| 02 – Iron (Fe)         | Comparison of non-magnetic, ferromagnetic and antiferromagnetic configurations of bcc iron. |
| 03 – Platinum (Pt)     | Investigation of non-magnetic and spin-polarised fcc platinum.                              |
| 04 – Iron oxide (FeO)  | Investigation of local magnetic moments and magnetic ordering using DFT+U.                  |

## Software and requirements

The practical examples require:

* [VASP](https://www.vasp.at/): Electronic-structure calculations.
* [Materials Project](https://materialsproject.org/): Obtaining initial crystal structures.
* [VASPKIT](https://vaspkit.com/) or qvasp: Alternative structure preparation and conversion tools.

Access to the appropriate PAW pseudopotentials and computational resources is also required.

## Getting started

It is recommended to begin with the background material before proceeding to the individual calculations. Each practical example contains its own input files, calculation instructions and discussion of the results.

The calculations are intended as educational examples. Computational parameters should be tested for convergence before applying the methods to independent research projects.
